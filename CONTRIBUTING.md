# Contributing to STOR1

Thank you for considering contributing to STOR1!

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.

## How to Contribute

1. **Fork & Clone**: Fork the repository and clone it locally.
2. **Branching**: Create a feature branch off `main` (`git checkout -b feature/my-feature`).
3. **Environment Setup**: Copy `.env.example` to `.env` and fill in local development credentials.
4. **Development**: Run `npm run dev` to start the local Vite server.
5. **Linting & Testing**: Ensure code passes `npm run lint`, `npm run typecheck`, and `npm run test`.
6. **Submit PR**: Push your branch and open a Pull Request against `main`.

## Pull Request Guidelines

- Keep changes focused and clear.
- Ensure all CI checks pass.
- Write tests for new functionality where applicable.
