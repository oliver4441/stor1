# Omix Marketplace v2

A clean, no-nonsense marketplace for Kericho.

## Features
- **4 Core Pages:** Home, Listing Detail, Sell, and About.
- **Design System:** Dark theme by default, DM Sans font, Airbnb-style cards (14px radius), Red accent (#ff385c), subtle animations.
- **Architecture:** Multi-Page Application (MPA) for fast loading on 3G networks.
- **Data:** Pre-seeded mock data (since no backend is used in this frontend-only implementation).

## Tech Stack
- React 18
- Tailwind CSS
- Lucide Icons
